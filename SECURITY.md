# Security and privacy reports

Do not put private notes, databases, model files or credentials in public issues. Report a reproducible security concern privately through GitHub's available private reporting feature or the repository owner's public contact channel. Use fictional data for reproductions.

This evaluation app requests no INTERNET permission, stores data in its own Android sandbox and imports only a pinned model after size/SHA-256 verification. Model relevance is not guaranteed. Review all actions before applying. No arbitrary shell, network or external messaging tools are exposed to Llama. The preview uses a debug signing key.
