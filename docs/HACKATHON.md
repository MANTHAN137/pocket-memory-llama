# Hackathon contribution disclosure

**Project:** Pocket Memory · Built with Llama  
**Developer:** Manthan Dhole (solo)

Pocket Memory already exists as an Android app. Its Memory, Chat, Writing, Today, storage, inference and design foundations predate this hackathon. They must not be presented as newly built work.

This edition adds or adapts:

- A Meta Llama-only model catalog and in-app download → verify → Use setup.
- Simpler model selection while retaining Pocket Memory's actual screens.
- A narrow MCP client for explicit Exa web research and one local Llama answer.
- Application-owned tool, traffic, context, output, repetition, cancellation and deadline limits.
- A local, expiring Android browser companion exposing actual WebMCP tools.
- Fictional-data verification and documentation of those changes.

Meta Llama 3.2 3B is the only offered language model. No hosted Meta API or Muse model is used. No API-credit redemption or model-specific bonus eligibility is claimed.

The participant guide excludes basic RAG apps. Existing memory Q&A alone does not establish eligibility. The submission should accurately demonstrate the new MCP/WebMCP integration; the organizer decides whether it qualifies. Do not invent a different product to fit a track.

The owner authorized publishing this edition in the Llama repository. Final organizer permissions remain pending. No application has been submitted.
