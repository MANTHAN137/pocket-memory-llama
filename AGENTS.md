# Pocket Memory

Work only in this checkout, package `com.pocketmemory.llama`. Do not make unrelated application or release changes.

Keep inference on Android. The sole offered model is Meta Llama 3.2 3B. Llama selects candidate IDs; the app orders phases; task text must come from an allowed source action. Never bypass human review, source freshness, atomic apply, deduplication or guarded undo. Cancellation must be scoped to its original job.

Never commit model weights, signing keys, private source, personal databases, backups or credentials. Vendored code retains upstream notices. Fictional fixtures run only on an isolated emulator, never a physical phone.

Build with JDK 17 and the pinned tools. Run the model catalog check, build/lint and actual offline emulator workflow for inference or task-state changes. Recorded media must disclose editing and avoid unsupported quality or speed claims. New work must be distinguished from pre-existing foundations.
